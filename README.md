Catchpoint is a leading Internet Performance Monitoring (IPM) company. Its platform combines the largest independent global observability network (thousands of synthetic agents across 100+ countries plus BGP peers) with synthetic monitoring, real user monitoring (RUM), BGP monitoring, endpoint/workforce monitoring, tracing, and Internet Sonar to give teams end-to-end visibility across the entire Internet Stack — networks, DNS, CDN, SASE, and third-party services — from the end-user perspective. Catchpoint exposes a REST API v2 (bearer API key, JSON) for managing synthetic tests, monitoring nodes and node groups, products/folders, alerts, contacts, SLOs, insights, and usage reporting, plus alert/test-data/BGP webhooks and an official Terraform provider. Catchpoint is a portfolio company of Sapphire Ventures.

**Areas:** Company · DevOps · Monitoring · Observability · Internet Performance Monitoring · Synthetic Monitoring · Real User Monitoring · Network Monitoring · BGP Monitoring · Digital Experience Monitoring

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Catchpoint: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
